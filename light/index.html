01 — The opportunity

The hard part is already done. The last mile is missing.

Muka Tangata and industry have built something real — a skills-first dataset across four food & fibre industries: roles, the skills each needs, how they cluster, how they transfer. It's a genuine asset, and it should be protected.

The problem isn't the data. It's the delivery. PowerBI was built to display information for industry — not to guide a 15-year-old. This pilot's real job is the translation layer: same trusted data, rebuilt into a guided experience a young person can use with zero instruction.

01

Built to display, not to guide

A wall of filters and workforce jargon. For youth, it's the opposite of inviting — they bounce.

02

Fragile underneath

Per-industry Excel workbooks merged by VBA macros. It breaks the moment you add a fifth industry.

03

One tool, every audience

Employers, career-changers and youth need different things. Serving everyone at once serves no one.

03 — How we'll build it

Configurable where it should be. Custom where it counts.

You asked for the balance between custom build and configurable tools. Here it is — a no-code layer for the data and content, a custom build for the youth experience, where the journey is the product.

The data, structured
One relational source of truth. Add an industry by adding linked records — not by merging another spreadsheet.
System architecture
Data updates reach the app with no developer and no rebuild — so the pilot iterates continuously, every sprint.

Backend Single source of truth

One structured, relational store replaces the Excel + VBA + manual-merge pipeline. Adding a new industry is adding linked records — no model rebuild, no corruption risk.

Frontend The youth experience

Custom-built, because off-the-shelf can't deliver a guided journey that converts. Next.js on Vercel — the stack we run daily — quick to iterate between testing rounds.

CMS Run by non-technical staff

Your team edits text, roles, industries and descriptions in a familiar, spreadsheet-style interface. No code, no deployment, no way to break the live app.

Cost Lean by design

Runs on near-free hosting and a low-cost data tier — roughly NZ$0–80/month across the pilot. No enterprise platform, no heavy licensing.

Built by youth. For youth.

An 18-year-old founder + a youth core from a VUW hackathon, building for 13–30s. The empathy is structural — not researched.

Who's building it

Your developer already ships production software.

This isn't a learning exercise on YEA's budget. It's built by someone who designs, builds and deploys real web apps for paying clients — on the exact stack this pilot runs on.

04 — Youth engagement · VUW hackathon

It's about youth employment.
So youth help build it.

We'd open the pilot with a hackathon at Victoria University of Wellington. Rangatahi generate ideas for the tool, and the standout few become a small core of 2–3 youth contributors on the testing team, through course-credit and volunteer pathways, so it stays light on the budget.

A VUW hackathon

Run through our Victoria University and the Atom connections. A day of youth energy that crowdsources real ideas and surfaces the people worth bringing on.

2–3 youth contributors

A small core who run testing and help reach NEETs peer-to-peer. Course-credit or volunteer pathways available, so it stays low-cost and authentic.

Youth voice, every sprint

The brief mandates embedded youth voice. The hackathon plus the core make it real and continuous — not a box ticked once.

Near cost-neutral. The hackathon can run through a VUW partnership and contributors via course credit — so youth engagement adds ideas, reach and credibility without a heavy line item. Still highly fundable (MYD, Simplicity) as a youth-employment initiative.
